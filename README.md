# 魔女贝壳 · 课程研发与备课 Skill

面向成人技能类教师和培训讲师，首批支持 AI 学习、内容创作、女性成长课程。以教师端工作台为中心，管理备课项目、研究来源、教案与课件、审核状态、教师侧成长徽章和课程版本。学生侧徽章/证书仅作为讲师可选设计的课程素材。

## 使用

将仓库根目录作为 Skill 目录，或把 `SKILL.md` 与 `references/` 提供给支持 Skill 的助手。

- “先研究并建一门 AI 学习课的知识库，再分初中高级。”
- “给职场女性设计一门边界沟通技能课，不要求学员公开个人经历。”
- “设计一门短视频内容创作实战课，包含公开课、作品集作业与评分量规。”
- “按我的教案做 PPT、逐字稿、学生讲义、招生海报、作业、考试与证书。”
- “我上传了历年课件和同行材料。请盘点来源、提炼知识树与缺口，再生成完整备课包。”

## 完整备课包

用户提出“备课包/全套课程物料/可以直接开课或招生”时，默认生成课程总案、招生海报、可编辑 PPTX、逐页讲师逐字稿、学员讲义、学员作业纸、教师答案与量规、学员证书稿、交付索引与质量检查；公开课另补课前课后及现场运营附件。缺失的日期、场地、链接等以显眼占位符呈现。

## 结构

- `SKILL.md`：触发、流程、方法、输出要求与质量门槛。
- `references/`：设计原则、学习方法证据、全球对标、成人领域包、教师端工作台，以及 PPT、逐字稿、学员讲义、海报、证书和作业的制作规范。
- `references/09-备课包交付规格.md`：文件级必交清单与验收标准。
- `references/10-资料蒸馏与对标模板.md`：用户课程资料、同行/竞品材料的知识库蒸馏模板。
- `references/11-质量与试讲评估.md`：质量评分卡、资料批处理、可教知识卡、迁移检查和试讲改版模板。

## 设计原则

以成人学习者能做出的成果为中心；目标、评价、活动对齐；来源和假设可追溯；学习方法按任务选择；教师端进度依据备课产物；不夸大课程效果、名师排名或转化数据。
