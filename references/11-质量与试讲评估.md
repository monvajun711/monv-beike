# 备课质量评分、资料批处理与试讲评估

此文档给出统一的自评与审阅模板。评分针对**课程设计/交付材料的证据充分度**，不是讲师排名，也不能替代真实学习效果评估。没有学生/试讲证据时，结论只能是“设计已审/效果未验证”。

## A. 备课包质量评分卡

### 评分尺度

| 分值 | 锚点 |
|---:|---|
| 0 | 缺失、明显错误或与课程目标冲突 |
| 1 | 有提及但基本不可执行；缺乏可核对证据 |
| 2 | 部分可用；仍有关键缺项/不一致，需要实质修改 |
| 3 | 基本可执行、符合约定；仅有小修订项 |
| 4 | 证据明确、跨材料一致、可供讲师直接使用；验证方式/边界已说明 |
| N/A | 经说明不适用，例如不招生课无需招生转化物料；不得用 N/A 隐藏缺失 |
| NE | 证据不足，当前无法评判。NE不计入均分，但必须列出补证方式；阻断关键维度时总体验收不能通过 |

### 维度与审阅证据

| 维度 | 核心问题 | 评分证据示例 | 关键维度 |
|---|---|---|---|
| 1. 学习目标清晰度 | 谁在什么条件下能完成什么，标准是什么？ | 可观察目标、先备条件、成功标准、范围/不承诺 | 是 |
| 2. 目标—证据—教学对齐 | 是否教了要考的内容，评价是否真正测目标？ | 目标追踪矩阵、练习、量规、评价题/实作任务 | 是 |
| 3. 练习充分性与递进 | 学员是否从示范到支架练习，再到独立/变式练习？ | 每个核心技能的示范、练习次数/时间、难度递进 | 是 |
| 4. 反馈闭环 | 反馈是否说明下一步，且有反馈后再试？ | 反馈提示、错误分支、重做任务、再检查标准 | 是 |
| 5. 迁移与延迟保持 | 是否设计新情境应用与合适的延迟检查？ | 课后真实任务、复习节点、独立完成证据 | 技能课是 |
| 6. 知识结构与覆盖 | 内容结构清楚，重复/缺口/先修已检查？ | 知识树、MECE边界、来源/需求覆盖矩阵 | 是 |
| 7. 事实与来源可追溯 | 关键主张有来源、日期、状态和边界？ | 来源台账、锚点、事实/推断区分、过期核验 | 是 |
| 8. 资料摄取完整度 | 用户给的资料有清单、读取状态和未处理队列？ | 文件数量对账、批次状态、OCR/转写复核项 | 有用户资料时是 |
| 9. 跨文件一致性 | PPT、讲稿、作业、答案、证书、海报是否一致？ | 同一版本/目标/时长/价格/日期，页码映射 | 是 |
| 10. 课堂可执行性 | 时间、活动、资源、讲师操作和备用方案能否落地？ | 累计分钟、材料清单、分工、应急/超时路线 | 是 |
| 11. 可访问性与学习者安全 | 参与方式、阅读性、隐私和敏感内容边界是否合适？ | 替代参与方式、匿名/退出选项、版权/隐私处理 | 按领域为关键 |
| 12. 文件可用性 | 文件能否打开、编辑、打印、阅读？ | 可编辑格式、渲染、分页、裁切、学生/教师版区分 | 是 |

### 计算与结论规则

- 报告每项分数、证据定位（文件/章节/页码/知识卡ID）和缺项。不要只交总分。
- 均分 = 所有适用且已评分维度的分数总和 ÷ 这些维度数量；N/A 和 NE 不计入。说明分母，例如 `34/40，8个已评分维度`。
- **通过（设计层）**：所有关键维度 ≥3，无阻断项，整包文件/跨文件检查通过；并显式写“尚未验证实际学习效果”。
- **有条件通过/待修订**：无阻断项，但任一关键维度为2，或非关键维度存在1–2；列出责任人、改动和复核条件。
- **未通过**：任一关键维度为0–1，或存在下列阻断项。局部高分不得抵消。
- **证据不足**：关键材料/用户资料不能读取或学习证据尚无；明确待补项，不能伪造估分。仅交设计阶段时可评“设计可审”，不可评“教学有效”。

### 阻断项（不通过直至修复/人工确认）

- 课程核心事实/安全/法规/价格与权益有明显错误或未核实且已被写成确定承诺；
- 课程目标缺失，或目标没有任何教学机会/评价证据；
- 考试要求学员完成未教、未练的关键技能；
- 学员版泄露答案、个人/未成年人信息外发，或存在严重版权/授权疑点；
- 关键文件无法打开、讲课总时长明显错误、PPT与逐字稿结构冲突；
- 证书声称认证/资格/能力，但没有实际评价标准与证据；
- 未经处理的高风险缺口会误导学习者或造成伤害。

## B. 批量资料摄取清单

### 处理状态定义

`待处理`：已登记但未读取。  
`可读已处理`：目标相关部分已完整检查，并记录锚点。  
`部分读取`：只处理了部分章节/页/时间段；注明覆盖范围。  
`需人工复核`：OCR、转写、格式、歧义或权利问题可能影响结论。  
`无法读取`：当前工具/格式/权限无法读取；不是“资料不存在”。  
`排除`：与目标无关、重复或用户要求排除，并写原因。

对账：`登记总数 = 已处理 + 部分读取 + 需人工复核 + 无法读取 + 排除 + 待处理`。状态互斥，每项只计一类；部分已处理完毕的文件状态采用“部分读取”，具体已读覆盖范围写入记录。公开 URL 需记录访问日期和可访问状态。

### 资料优先级建议

- 高：用户明确指定的核心教材/标准、自有课程主干、当前课程直接证据、近期权威资料。
- 中：补足核心模块的参考材料、具备明确教学机制的同行公开样课、历史学员反馈/作品（授权与去标识化后）。
- 低：重复、宣传性强而缺少可核验内容、年代久远或与目标距离较远的材料。

优先级是处理顺序，不代表可信度。对高风险事实仍按来源质量和时效审核。

## C. 可教知识卡补充字段

在 `references/10-资料蒸馏与对标模板.md` 的原子知识卡基础上，核心知识卡补齐：

```markdown
- 学员常见错误/错误思路：
- 错误原因假设/诊断问题：
- 讲师示范/范例（示范哪一步判断）：
- 带支架练习：
- 练习变式/难度递进：
- 独立练习：
- 达标样例（来源/虚构标记）：
- 未达标样例及可观察差异（来源/虚构标记）：
- 反馈规则：
- 反馈后重试任务：
- 课后迁移任务（换了什么情境/约束）：
- 延迟保持/迁移检查点：
```

简短公开课可用“一次示范 + 一次支架练习 + 一次独立微任务”，多周技能课应加入变式、独立练习、反馈后重试与后续应用。数量依复杂度决定，不能因为表格字段齐全就判断练习充分。

## D. 即时、延迟与迁移证据计划

| 学习目标 | 课内即时证据 | 支持条件 | 课后迁移任务/新情境 | 延迟检查点 | 达标标准 | 记录方式/责任人 | 状态 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  | 未测/待实施/已收集 |

判断原则：

- **即时表现**说明学员在当时条件下做到了什么；记录提示、同伴协助、工具支持等条件。
- **独立迁移**要求学员在至少一项关键情境变化下，独立或使用课程允许的正常工具完成类似任务；量规保持目标标准可比。
- **延迟保持**复访核心知识/技能，时间点依课程跨度和应用节奏确定，不套固定天数。
- 课程太短、无法后续联系时，提供可选自测/复习卡和自我记录方法，但把外部表现写作“尚未观测”，不能推断达成。
- 满意度、推荐意愿、出勤、签到、完成材料、付费和转化属于体验/运营数据，不是学习掌握证据。
