# 备课包交付规格

## 何时进入整包模式

以下表达均默认触发整包文件交付：“帮我做一个备课包/全套教学物料”“按这个 Skill 完整备课”“要能直接开课/招生”“课程需要海报、PPT、逐字稿、作业和证书”。用户只要某个单项、只要文字构想或明确缩小范围时，按指定范围工作。

## 必交文件合同

| 交付物 | 默认文件形态 | 最低内容/验收 |
|---|---|---|
| 交付索引 | Markdown | 文件清单、用途、格式、版本、完成状态、占位符/待确认事实、替代项原因 |
| 课程总案 | Markdown 或 DOCX | 课程简报、目标、学员起点、课程地图、知识/技能结构、课时安排、目标—活动—评价追踪、材料清单、风险、来源 |
| 招生海报 | PNG/JPG + 可编辑源稿（能生成时） | 主标题、学员对象、真实成果、课程形式/时长、日期地点费用报名 CTA；事实缺项用明显占位符；输出手机竖版优先，另附文案和图片替代描述 |
| 课程PPT | PPTX | 可编辑、按授课节奏制作；有讲师备注或关联逐页讲稿；包含实际练习说明；检查字体、文字溢出、页数、图像来源、页面渲染 |
| 讲师逐字稿 | DOCX 或 Markdown | 每页对应 PPT 页码；开场、核心解释、示范、问题、学员指令、预期回应/追问、停顿、转场、应变和超时删减；全课分钟数核算 |
| **学员讲义** | DOCX/PDF，建议保留可编辑源文件 | 供学员跟课、记录和课后复习；含课程地图、关键概念/流程、例子、对应练习提示、自检问题和真实可写的笔记留白；与逐字稿、练习纸分工，不以二者替代。默认每教学小时约1–2页正文，复杂课按需增加，不以填充凑页数 |
| 学员练习/作业纸 | DOCX/PDF 或可填写格式 | 学员版任务说明、目标、步骤、用时、提交形式、作答区域、资源、隐私/版权/AI规则；可独立打印或发送 |
| 教师答案与评价包 | 独立 DOCX/Markdown/PDF | 参考答案/样例、Rubric、常见错误、反馈话术、补交/补救方式；不混入学生版导致答案泄漏 |
| 学员证书 | DOCX/PPTX/可打印PDF | 默认参与证明；姓名、课程名、日期、颁发方字段；课程完成/能力证书须匹配真实完成条件/考核证据；无真实核验机制不加假编号/二维码/印章 |
| 来源与QA | 总案章节或独立文件 | 关键主张来源、日期/地区/限制；批量资料清单及读取状态；质量评分卡逐维证据；跨文件一致性核对；导出和打印检查结果 |

整包通常还需一个可执行课程时间表/教案。短工作坊可直接放进课程总案；多课次课程单独给课次教案。只要有现场教学或学员需要跟课/复习，学员讲义即为必交项；纯演示且用户明确不需学员材料时可注明不适用。公开课或招生课程附课前通知、报名说明/FAQ、签到表、课程反馈表、后续产品说明与自愿 CTA；不同课型可增减。

## 学员讲义设计与课时配比

学员讲义是 learner-facing 的教学伴随材料，帮助学员定位课程结构、理解关键词、跟上讲解、记录个人判断并在课后复习。它与其他材料分工：PPT服务投影和集体注意力；讲义服务个人跟课、记笔记和回顾；逐字稿服务讲师备课与讲授；练习/作业纸要求学员完成明确任务并提交/自检。内容可共享目标、术语和例子，但讲义不复制整份逐字稿，也不能用练习纸替代。

默认页数按**教学小时**（不含休息）估算每小时1–2页正文。短课至少提供一张可跟课/复习的材料；复杂操作、公式、案例或学员需要写较多推理时可增加。页数是备课容量的起始假设，不是教学效果阈值；禁止重复填充。课堂前按实际打印版检查页数和使用节奏。

每个课时/模块按目标选择以下内容：

1. 本节成果及其在课程地图中的位置；
2. 少量关键概念、术语、流程或决策规则，用白话解释；
3. 短例子、图表、示范摘要或与讲师演示对应的观察问题；
4. 跟课提示与真实可写的笔记/反思空白；
5. 与课堂练习名称、编号、时间、产出、成功标准一致的链接提示；需要独立评分的答案只放在教师版；
6. 课程回顾、自检/检索问题；多课次课程可附复习或迁移提示；
7. 重要主张的来源、素材署名和使用边界；未核实内容标记为假设/待确认。

### 排版与可访问性

- 使用清晰标题和逻辑顺序，让学员快速定位；优先可编辑 DOCX/HTML，必要时导出打印 PDF；使用文档标题样式和明确表头。
- 打印正文默认不低于12pt（仅来源等辅助文字可例外并需仍可读）；优先简洁字体、高对比，黑白打印仍能理解；颜色不作为唯一编码。
- 给跟课记录留足书写空间，空白应对应明确提示；不以大量空线制造页数。
- 复杂内容可用图表并配文字说明；避免文字墙、拥挤表格、浅色小字。适用时提供纸笔/电子或口头参与替代。
- 发布前检查屏幕阅读/放大打印需求、分页、空白能否实际书写、来源与素材授权。

公开实践参考：Cornell Teaching Innovation 建议用 skeleton notes（提纲、提示和书写位）支持课堂记笔记；University of Waterloo 的无障碍指南强调讲义顺序清楚、易读并考虑放大版；CAST UDL 强调以多种方式支持参与、信息呈现及表达。这些是设计参考，不表示单一讲义格式必然适用于所有学习者或保证成绩提升。

## 课程事实卡（生成前的单一真相源）

```yaml
课程名与版本:
主办方/讲师（仅真实资料）:
学习者/人数/先备:
课程形式/总时长/日期/时区/地点或平台:
可观察的学习成果:
课程包含与不包含:
作业/评价/达标标准:
价格/优惠/退款与取消规则:
真实报名链接/联系方式/容量:
品牌/素材/授权限制:
已核实事实:
设计假设:
用户待确认:
来源及核验日期:
```

不因缺项停止可独立推进的工作。对会影响布局的字段留 `[待确认：日期]` 等显眼占位符，并在索引中汇总。严禁把占位字段隐藏进小字或导出为看似已确认的信息。需要二维码时必须用事实卡中的真实 URL 生成并扫描验证；没有 URL 则排版真实可点击 CTA/占位符。

## 生成顺序

1. 建课程事实卡、学习目标和需求—目标—证据追踪矩阵。
2. 设计时间线、学员活动和评价；先算总时长，再排PPT页。
3. 生成教案和逐页讲稿，保证原话、活动、示范和时间可执行。
4. 制作学员讲义：按每教学小时约1–2页估算跟课骨架、概念/例子和笔记空间；校对 PPT、讲稿和练习术语。
5. 生成学员练习纸和分离的教师答案/量规。
6. 根据真实课程权益写招生文案，再制作海报；海报不能先于课程事实定稿。
7. 按真实证据制作参与/完成/能力证书，明确性质。
8. 制作PPT及备注，标注来源/图片替代描述；同步检查页码与讲稿。
9. 出交付索引和跨文件QA；导出并检查每个可视文件。
10. 对整包运行质量评分卡，分别标注通过项、低分项、证据不足项和阻断项；缺少试讲数据时只判设计层，不判教学有效。

如果用户急需某个文件，优先完成该文件及最低配套材料；整包触发时仍维持清单，未完成项标状态和下一步，而非假称完整。

## 公开课/线下工作坊运营附件

按现场形式选择提供：

- 课前通知：时间地点/交通、入场、设备/账号/软件、是否需自带电脑、无障碍或替代参与方式、隐私与拍摄说明、取消联系。
- 签到/名册：只收组织所需的最少信息，提供不公开展示姓名的选项。
- 课堂运行表：讲师/助教分工、投影/音响/网络/计时、桌组、材料发放和作品展示顺序。
- 学员练习纸/桌面提示卡：任务、时长、步骤、成功标准、提交/分享方式。
- 技术与时间预案：无网、算力耗尽、生成延迟、设备不可用、超时和学员缺席时的替代流程。
- 课后反馈表：目标是否达成、哪一步卡住、最有用/需改进项、后续联系的自愿选择。
- 后续销售说明（若存在）：产品内容、价格、包含/不包含、工作量、适配/不适配、退款/延期规则、咨询/报名 CTA 和自愿说明。

## 文件格式与视觉资产

- 优先遵从用户要求的格式；否则 PPT 用 PPTX，文档用 DOCX/Markdown，打印用 PDF，海报交 PNG 并保留可编辑源文件（如工具支持）。
- 新海报需要原创视觉时可调用 imagegen 生图；生成图不得含文字或二维码（除非生成模型准确性经验证且有意采用），文字/CTA 后期排版以便核对。遵循现有品牌资产和授权。
- DOCX/PDF/幻灯片使用对应文档或演示工作流；生成后按适用流程渲染、逐页视觉复核，不能只凭文件存在判断通过。
- 文件名明确角色：`讲师版`、`学员版`、`教师答案`、`可发布待填信息`。避免把内部答案随学生版一并发出。

## 整包验收清单

### 目标与教学

- 每个目标至少对应一个练习/教学活动和一项可观察评价证据。
- 所有活动、休息、签到、提问、设备切换和转场均纳入时间；总分钟数精确吻合。
- PPT的示范和活动有学员操作时间；逐字稿提供清晰口令、反馈、转场和失败分支。
- 作业适量、答案/量规与补救方式完整，学生纸不泄露教师答案。
- 核心技能至少经历示范、带支架练习、独立/变式练习、反馈后再试；设计课后迁移任务和延迟检查，或明确注明当前不能测。

### 文件互相一致

- 课程名、版本、受众、学习目标、核心术语、日期地点、时长、费用、授课方式、PPT页码、证书措辞均来自同一事实卡。
- PPT每页能在逐字稿中找到对应段落；讲稿时长、休息和活动时长与教案一致。
- 海报承诺只覆盖课程实际可交付且有教学设计支持的成果；价格和报名入口与报名说明一致。
- 证书仅证明真实的出席、完成条件或评价证据，不作过度认证主张。
- 备课质量逐维度评估，关键项达到门槛且无阻断项；均分不能抵消关键缺陷。
- 即时作品、延迟保持、迁移表现、满意度/运营数据分别报告，不相互替代。

### 可用性与发布

- PPTX可打开/可编辑；所有页面渲染检查标题、正文、图表、脚注和备注关联。
- 海报以手机缩略图检查主标题、时间/地点、费用和报名 CTA；裁切后关键字仍可读。
- 证书姓名/日期/签发方留足填写区，黑白打印仍清晰；作业纸按A4/用户指定纸型打印检查。
- 学员讲义检查每教学小时页数、实际笔记空间、正文可读字号、黑白打印、章节导航、可编辑性和练习/PPT术语一致性；学员版不含内部答案。
- DOCX/PDF分页、表格断页、字体、页码、超链接和打印边距正确。
- 图片、字体、音乐、案例、学员作品及讲师资历拥有授权/来源记录；敏感信息最少化。
- 外发前由讲师确认所有标记项；未确认文件清晰标为草稿，不伪装成可发布最终版。
