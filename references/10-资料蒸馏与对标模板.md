# 用户资料蒸馏与竞品/同行对标模板

用于接收用户既有资料、公开同行课程、竞品招生/课程页面、公开课录像/讲义、研究来源和其他 Skill。它把“材料读过了”变成可追溯课程知识库，而非堆叠摘要。

## 1. 资料台账

| ID | 标题/文件名 | 作者/机构 | 类型/主题 | 日期/版本 | 来源链接/路径 | 权利状态 | 隐私风险 | 可信/证据类型 | 本次用途/状态 |
|---|---|---|---|---|---|---|---|---|---|
| S01 |  |  | 用户课件/公开页/论文/同行案例/其他 |  |  | 自有/授权/公开/未知 | 无/需匿名/敏感 | 一手/研究/机构说明/营销主张/经验 | 纳入/部分/排除 |

权利状态“公开”只表示公开可访问，不等于可复制、改编或再发布。未知/限制项可作为有限分析或事实核验线索；不得整套重制原作品。记录用户对自有文件的用途授权范围，例如仅供本次备课、允许内部复用、允许外发或不确定。

```markdown
- 关键定义/术语：
- 流程/原则/决策规则：
- 例子、反例、常见错误：
- 适用对象/前提/边界：
- 证据类型及强弱：
- 需要外部核验的事实：
- 版权/隐私/发布限制：
- Skill的教学改写（与来源观点分开）：
- 置信状态：提取准确/需OCR复核/存在歧义/待用户确认
```

## 3. 原子知识卡

```markdown
### K-001｜知识点名称
- 所属知识域/模块/层级：
- 一句话定义：
- 为什么对本课程重要：
- 原理/步骤/决策条件：
- 示例：
- 反例/失败案例：
- 常见误区：
- 适用条件与不适用边界：
- 先修/关联/后续节点：
- 学员可观察表现：
- 推荐教学方式/练习：
- 学员常见错误/错误思路及可能原因：
- 讲师示范/范例（展示的关键判断）：
- 带支架练习与独立/变式练习（难度递进）：
- 达标样例与未达标样例（注明真实/虚构及可观察差异）：
- 反馈规则与反馈后重试任务：
- 课后迁移任务/延迟检查点：
- 评价证据与达标描述：
- 来源ID与锚点：
- 来源状态：用户材料 / 多源印证 / 权威来源补充 / 同行做法 / 营销主张 / 专业推断 / 待核
- 版本/核验日期/责任人：
```

知识卡按真实主题裁剪；不为填满字段而杜撰证据或例子。区分“必须学会”“支持理解”“拓展选修”。
核心技能卡需包含上述示范、递进练习、反馈后重试及迁移字段；非核心知识点可精简，并注明不适用理由。虚构示例不得标作真实学员成果。

## 7. 与用户对话的蒸馏回述

```markdown
我从你提供的资料中读到：
1. 课程最终想解决的问题/受众：…
2. 资料里反复出现的核心模块：…
3. 值得保留的教学机制：…
4. 资料之间的冲突、重复或时效问题：…
5. 目前缺的关键内容：…
6. 初步知识树/学习路径：…

来源区分：用户自有材料…；公开对标…；外部权威补充…；我的教学设计推断…
假设：…
待确认（最多3项）：…
```

先看当前对话中用户已经给过的信息。只问会显著改变课程方案的事项；其余用假设推进。用户补充后记录“决策—影响的目标/模块/物料—版本”。
