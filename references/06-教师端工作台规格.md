# 教师端工作台规格

## 产品边界

魔女贝壳的核心应用服务讲师备课。工作台保存的是课程项目和教师工作成果。学生端进度/徽章/证书只是可选的课程组件模板，不是此工作台默认的学习者管理系统。

## 教师项目结构

每个课程项目建议保存：

1. **课程简报**：主题、受众、需求、成果、格式、时长、约束、假设。
2. **研究库**：来源、主张、证据标签、适用范围、引用位置、最近核验日期。
3. **知识架构**：主题树、概念关系、先修关系、误区、覆盖/排除范围。
4. **课程地图**：模块、层级、课时、目标、证据、练习、作业。
5. **教学物料**：教案、PPT、逐字稿、讲义、练习和评价包的链接/版本。
6. **审阅任务**：待核事实、专家/同行意见、修订记录、交付前勾选。
7. **运营复盘**：试讲时间偏差、学员作品/匿名证据、反馈与下版改动。

## 项目状态

状态是可回退的看板标签，不是不可跳过的关卡：

`想法/需求待定 → 研究与建库 → 课程架构 → 单课备课 → 讲师审核 → 可授课 → 试讲复盘 → 已迭代`

用户有紧急需求时允许从中途开始，并把未完成的前置工作标记为风险或待办。

## 教师端指标

优先展示能帮助讲师做决定的指标：

- 备课产物完成度（如课程地图、教案、PPT、评价包）；
- 目标—活动—评价对齐问题数；
- 待人工核验的事实/过期来源数；
- 试讲后的高频误区与目标达成证据；
- 课程版本与复用模块；
- 备课投入时间（仅作为个人流程参考，不用于评价教师优劣）。

不得把“已生成页数、课程数量、登录天数”宣传为教学质量。

## 教师技能徽章与等级

这些只用于工作台里的自我进度提示，不是官方资质认证。教师可以隐藏、重置或关闭。徽章必须对应可复核产物：

| 成长阶段/徽章示例 | 解锁证据 |
|---|---|
| 课程定锚者 | 完成课程简报并定义可观察成果 |
| 来源守护者 | 为关键主张登记可靠来源、日期与限制 |
| 对齐设计师 | 完成目标—证据—活动追踪矩阵并清除孤儿目标 |
| 课堂编排师 | 课时合计核对通过，讲师动作与学员练习清楚 |
| 评价设计师 | 作业/口笔试映射目标，附答案或量规 |
| 讲师实战者 | 完成试讲并记录时长、理解检查与复盘 |
| 迭代教研者 | 有基于学习证据的版本变更记录 |

不要自动排名讲师。若设计“等级”，采用成长描述，不设置竞技榜或未审核的“专家/大师”称号。徽章的解锁应允许申诉/人工更正，证据可导出。

## 学员侧组件（可选）

当讲师明确要为课程设计学员激励时，工作台可生成单独的课程组件：能力等级标准、徽章名称、证书文案、达成证据、补做机会、无障碍替代方式、隐私和公平性检查。显著标注“此组件服务学员课程”，不计入教师的工作台徽章/项目进度；默认不开启公开排名。

## 课程版本管理

- 版本变更记录日期、作者、变更范围、证据/反馈、影响课次和需重新审阅的材料。
- 只变文案可做小版本；学习目标、评价标准、风险政策或结构变化应升级主版本。
- 派生课程保留原课程来源和差异说明，避免复用过期事实。
- 对动态主题（AI 工具、平台规则等）显示“最近核验日期”和复核提醒；过期不自动表示错误，但要阻止未提醒的确定性呈现。

## 隐私与权限

- 默认只存课程设计内容，不要求上传学员名单、敏感画像或个人经历。
- 如确需学情信息，优先用聚合、去标识数据；定义用途、权限和保留期限。
- 学员作品展示须获得授权，面向工作台的数据默认讲师私有。
- 女性成长课程的个人故事、健康/关系/财务细节不得进入徽章证据或公开成就墙。

## 最小可用验收清单

- 教师可建立多个课程项目，复制模板并导出成果。
- 状态可以回退或跳过，项目列表清晰区分待办与风险。
- 每个重要课程主张可追溯到来源与日期。
- 教案、PPT、逐字稿、评价互相关联且显示版本。
- 教师成就只根据备课/试讲/迭代证据；学员成就属于隔离的可选课程组件。
- 无学员敏感数据也能完成工作台主流程。
- 进度状态不对外误称教师认证、课程认证或教学有效性证明。
