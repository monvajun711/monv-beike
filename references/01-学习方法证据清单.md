# 学习方法证据清单

这份清单不是把“名词”当疗效承诺。任何方法都需看学习目标、学习者、领域、实施质量与研究条件。

| 方法/框架 | 常见用途 | 可采取的设计动作 | 证据/边界 |
|---|---|---|---|
| 间隔练习与检索练习 | 延长保持、发现遗忘 | 每课开头短时回忆旧知识；课后隔时复习；反馈纠错 | 有较广研究综述支持，但间隔安排需按材料与情境调整 |
| 形成性评价与反馈 | 让教与学依据证据调整 | 铰链问题、退出条、作品检查；反馈后再试 | 关键是证据引发下一步教学/学习行动，不是测验数量 |
| 逆向设计 / UbD | 多课次课程规划 | 先定迁移结果，再定证据，最后设计活动 | 是规划框架；效果依赖目标与评价质量 |
| 建设性对齐 | 检查课程内一致性 | 把目标、活动、评价放入同一映射表 | 课程设计原则；可减少错位，非单一学习法 |
| SMART 目标 | 让目标易于理解/追踪 | 检查具体性、可观察性、相关性和时间边界 | 管理/目标制定启发式，不等于学习科学理论 |
| 布鲁姆分类 | 设计认知任务范围 | 混合回忆、解释、应用、分析、评价、创造 | 分类工具，不是严格阶段模型；需领域化解释 |
| 费曼式讲回/自我解释 | 暴露理解断点、组织知识 | 用白话解释一个概念；标出卡住之处；回看材料后重讲 | 自我解释有研究传统；“费曼学习法”品牌式四步法缺少统一标准化方案，不宣称独立保证成效 |
| Worked example / 示范 | 初学者学习程序和复杂任务 | 展示完整范例与思路，再做相似变式，逐步撤掉提示 | 常用于减轻初学负担；须防止只看不做 |
| 交错练习 | 学会区分问题类型与选策略 | 基础形成后混合相近题型，要求判断用哪种策略 | 适用性因领域、学习阶段而异；不是所有内容都该交错 |
| 项目式/问题式学习 | 复杂应用、整合与协作 | 设置真实问题、里程碑、支架、反馈与评价量规 | 不应把“少讲授”当作定义；需足够先备和指导 |
| 同伴教学/讨论 | 解释、推理、观点比较 | 独立作答→同伴讨论→再次作答→揭示理由 | 需明确题目、参与结构与知识校验 |
| 双编码/多模态材料 | 支持理解复杂空间或过程 | 图示与文字互补，标注图中关系 | 避免装饰图、冗余字幕和无关动画；不等同“学习风格匹配” |
| UDL | 预先降低参与与表达障碍 | 提供多种表征、参与方式和表达通道 | 仍须维护同一学习成果标准；对具体学科应按证据验证 |
| 游戏化与徽章 | 反馈进度、庆祝阶段性成果 | 奖励可验证能力、进步、作品或复习行为 | 设计不当会挤出内在动机或制造羞耻；不是效果保证 |
| 学习风格匹配 | 常被用于按“视觉/听觉/动觉型”分组 | 不作为固定学员标签；按内容提供适当多种表征 | 证据不支持把学生按固定学习风格匹配教学的普遍主张 |

## 证据标签

- **综述支持**：系统综述/高质量综述在多项研究中有一致相关发现；仍需看适用范围。
- **研究支持**：有研究但范围/样本/领域有限。
- **设计框架**：结构化规划工具，不直接声称提高成绩。
- **假设/流行实践**：可试用、需测量，不当成已证实事实。

## 设计时的选法

- 记忆与事实：优先低风险检索、间隔复习、及时反馈。
- 新程序/技能：短段解释、思维示范、带提示练习、独立练习、纠错。
- 概念理解：对比例子、精细提问、自我解释、概念图和反例。
- 高阶迁移：真实任务、案例、项目、交错选择、论证和反思，前提是有足够先备。
- 全部场景：收集学习证据，依证据调节节奏与支持。
