# 教学交付物设计规范

## 共同原则：一个课程简报，多种交付物

开始做 PPT、海报、证书或作业前，建立同一份课程事实卡：

```markdown
- 课程名/版本：
- 目标学员/适合与不适合对象：
- 可观察学习成果（3–5 个核心结果）：
- 课程范围/明确不包含：
- 课时/形式/日期/时区/平台/地点：
- 学员需准备/预计课后投入：
- 作业与评价/通过标准：
- 讲师真实简介/可核实资历：
- 价格/真实名额/报名链接/退款与取消规则：
- 主办方/联系方式/品牌规范：
- 来源、用户确认项、待核验事实：
```

缺项时区分待补信息和可默认的设计选择。可先生成带醒目占位符的可审阅稿；日期、价格、URL、姓名、身份和认证不可臆造。所有产物标注相同课程版本，防止互相矛盾。

## PPT / 演示文稿

先确定时长、场景、受众起点、投影/屏幕、讲师风格、品牌与格式；缺失时声明假设。先安排互动、学员练习和反馈，再分配讲授页。按目标安排定位/激活、解释、示范、练习、检查、总结/下一步等页面职责，不机械套用固定模板或固定页数。

逐页交付字段：页码、预计分钟、页面职责、标题/核心信息、屏幕文字、图示/示例、讲师备注、学员动作/理解检查、来源/图片替代描述。每页保留清晰主信息；区分投影文字和讲师口述；数据标明来源、时间、单位和口径。活动页写清任务、时限、提交方式、成功标准。

可访问性 QA：正文能在实际投影环境辨读；重要含义不只靠颜色；前景背景对比足够；图表、图片、视频提供替代说明/字幕；阅读顺序清楚；来源和授权可追溯。对比度参考 WCAG 正常文本 4.5:1、大字 3:1；这只是颜色对比检查，不代表整份演示稿完全无障碍。若交付 PPTX/PDF，提供可编辑原稿并抽查导出后的字体、图表、链接、分页与裁切。

## 逐字稿 / 讲师手册

逐字稿按 PPT 页码和教案时间线组织：

| 时间/页码 | 讲师原话 | 动作/演示 | 提问 | 可能回应及追问 | 纠错/转场 | 备用方案 |
|---|---|---|---|---|---|---|

用自然口语和清楚指令，写明学员现在做什么、几分钟、如何提交。加入关键停顿、讨论、设备切换、答不出时的提示、超时删减项和线上故障备用方案。真实故事标为讲师待补，不捏造第一人称经历。核算发言、问答、练习、等待与转场的总时长，并和 PPT 页码逐一核对。

## 招生海报与配套招生文案

### 信息层级

1. 明确目标受众与可兑现的课程收获；
2. 课程名与形式；
3. 日期、时区、时长、地点/平台、费用；
4. 相关且可核验的讲师信息；
5. 清晰报名 CTA 和真实链接/二维码；
6. 适配条件、准备事项、退款/取消政策查看入口。

海报是入口，复杂内容放报名页。交付可包含短海报文案、社媒配文、完整报名页说明、视觉简报（尺寸、版式、字体气质、品牌元素、素材/授权需求）和发布核验单。按渠道设尺寸/比例和安全边距；用手机缩略图检查主标题、日期和 CTA。避免拥挤、低对比、复杂底图压字和多重主标题。提供纯文本版和图片替代描述。

宣传主张只承诺课程设计和评价可支持的结果，不保证收入、流量、治愈、晋升或人生改变。逐项核对日期/时区/价格/讲师资历/链接/真实名额/优惠/退款条款；没有真实限额就不写“仅剩 X 席”。免费公开课包含后续销售时，应清楚披露。


## 学员课堂讲义

讲义是学员跟课、记笔记和复习用的独立材料。它不是PPT打印版、讲师逐字稿或作业纸的改名；可以与它们共享结构和术语，但应补充学员视角的课程导航、概念解释、示范观察点、回顾提示和记笔记空间。详细文件合同与页数/可访问性验收见 `references/09-备课包交付规格.md`。

设计时先确认每段课程的学习目标和活动，再从课件提纲中抽取必要内容。默认按每教学小时约1–2页估算正文，不含休息；简单讲座可以更短，操作课/复杂案例可增加，页数不能靠重复凑齐。每节留真实可写的记录区域，并用提示引导记录（例如“我观察到的判断依据”“我需要追问的步骤”），同时保留开放笔记空间。练习任务、编号、时长与成功标准必须与课件和作业纸一致；教师答案仅放教师材料。

以12pt左右的打印正文作为默认目标，使用标题样式、清晰层级、高对比和黑白可读设计；需要大量手写时增大行距/留白。复杂信息提供图示加文字说明；有设备/阅读障碍时提供可放大或电子版/替代参与路径。交付前核对打印页数、留白、页码/章节、来源署名、可编辑性及学员是否能在不读逐字稿的情况下找到课堂重点。

## 证书与徽章

先确认要证明参与、完成还是经评价展示能力；措辞和版式的可信度不能超过实际评估。

| 类型 | 可以证明 | 最低信息 |
|---|---|---|
| 参与/出席 | 参加过活动 | 活动/课程名、参与者、举办者、日期；不暗示掌握技能 |
| 课程完成 | 满足事先公布的完成条件 | 完成条件、课程工作量/时长、日期、颁发方 |
| 能力证明/微证书 | 经评价展示指定能力 | 学习成果、评价方法/标准、证据类型、颁发方、日期、核验方式 |

验证编号、QR 或公开核验页只有在机构确实维护核验记录时才能加入。不得仿政府/大学印章，不得使用“认证/资质/执照”等超出授权词。提供可编辑稿和打印规格；数字验证链接可设为自愿公开，保护学员隐私。

## 作业与练习包

| 字段 | 必须回答的问题 |
|---|---|
| 对齐目标 | 练习或证明哪项目标？ |
| 情境与受众 | 为什么值得做？是否接近成人真实任务？ |
| 操作说明 | 做什么、步骤、格式、工具、提交方式？ |
| 时间负担 | 预计多久？哪些是必做，哪些可选拓展？ |
| 评价标准 | 量规、答案/范例、常见错误、反馈时间？ |
| 公平替代 | 是否有不同工具/情境/表达方式但保持同一目标？ |
| 隐私/版权/AI | 禁交哪些敏感数据；引用、授权和 AI 使用规则？ |
| 补救 | 不达标如何修改、重交、补练或获得支持？ |

成人技能作业优先交作品、演示或决策说明。样例标明虚构或获授权。评分标准在提交前公开；附反馈下一步，不以反思字数替代技能证据。AI 相关课程说明允许用途和披露方式，不要求提交敏感工作数据或他人信息。

## 联合交付包

课程材料整套制作时按顺序交付：课程事实卡/版本；PPTX 或页面脚本；页码对应逐字稿；独立学员讲义；招生海报文案/视觉简报/发布文案；课前诊断、练习/作业与 Rubric/答案；参与/完成/能力类型证书稿与徽章说明；统一来源表、待确认项和 QA 清单。讲师审核前，外发材料标为“待确认草稿”。

用户明确要求“备课包/全套/可以直接开课”时，执行 `references/09-备课包交付规格.md` 的文件级必交合同。招生海报需交图文件，不能只写视觉建议；PPT需交可编辑文件，不能只给页纲；逐字稿需逐页完整；学生作业纸、教师答案/量规分开；学员证书需给实际可编辑/打印版式。只有用户明确只要方案、文件生成能力不可用、或某种物料确实不适用时，才以相应替代物代替，并在索引中说明。
